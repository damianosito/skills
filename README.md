## Business Idea Feasibility

`business-idea-feasibility` produces evidence-led Red, Amber, or Green feasibility studies for business, app, SaaS, marketplace, product, and startup ideas.

It includes:

- live competitor and substitute research;
- competitor weakness and missing-market-needs analysis;
- a 12-category score out of 60;
- user-specific founder-fit analysis without embedding the author's biography;
- granular setup, legal, fixed, variable, support, and break-even costs;
- monetisation, legal, go-to-market, defensibility, and build analysis;
- kill criteria, a seven-day validation plan, and a minimal MVP;
- complete Red, Amber, and Green calibration reports.

### Install

In Codex, invoke `$skill-installer` and ask it to install the `business-idea-feasibility` skill from:

```text
https://github.com/damianosito/skills/tree/main/business-idea-feasibility
```

For a repository-scoped installation, place the `business-idea-feasibility` folder under `.agents/skills/`. For a user-wide Codex installation, place it under `$HOME/.agents/skills/`.

### Use

Invoke it explicitly:

```text
Use $business-idea-feasibility to evaluate this idea brutally honestly: [describe the idea]
```

The description also supports implicit activation when a user asks whether a startup, app, SaaS, product, marketplace, or side-hustle idea is viable or worth building.

### Important

The example reports are calibration artifacts, not current market research. The skill instructs the agent to verify competitors, prices, laws, platform rules, and market evidence live for every real evaluation.
